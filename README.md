# Автор: Алексюк К., группа 4ИСИП-323 УП.01.01 «Приём и ведение ЭМК» — WPF-приложение (C#, .NET Framework) 
Приложение для записи пациентов к врачам и ведения электронных медицинских карт (ЭМК).
Тема курсового проекта: «Проектирование и разработка базы данных для сервиса записи к врачам и ведения электронных медицинских карт».

## Возможности
 
**Пациент**
- Регистрация (ФИО, дата рождения, пол, полис ОМС, телефон, почта, согласие на обработку персональных данных; для детей до 18 лет ещё ФИО законного представителя).
- Запись на приём: выбор специализации, врача и свободного времени, указание жалоб.
- Талон на приём (печать и сохранение в файл), перенос и отмена записи, напоминание о приёме в ближайшие 48 часов.
- Просмотр своей медицинской карты: история приёмов, диагнозы, анализы, лечение.
**Врач**
- Список своих приёмов с поиском и фильтрами, отмена записи.
- Ведение приёма: жалобы, анамнез, анализы, диагноз по МКБ-10, назначение лечения, внесение в ЭМК (статус «Завершён»).
- История прошлых приёмов пациента; печать направления на анализы и рецепта.
**Администратор**
- Учётные записи (роли Admin, Doctor, User; для врача создаётся карточка врача: специализация, кабинет, стаж).
- Пациенты, записи на приём (изменение, отмена, талон), расписание врачей (создание и удаление времени приёма на период).
- Отчёты за период: приёмы по врачам, диаграмма, статистика по диагнозам; выгрузка в Excel, Word и PDF.

  ## Технологии
 
- C#, WPF (XAML), .NET Framework 4.8, Visual Studio 2022
- Entity Framework 6 (подход Database First), модель `Model1.edmx`
- Microsoft SQL Server (Express), база данных `323_EMK_ALEKSUK`
- Microsoft Office Interop (Word, Excel) для отчётов
## База данных
 
Двенадцать таблиц: `patient`, `user`, `specialization`, `doctor`, `schedule`, `appointment`, `medical_record`, `visit`, `diagnosis`, `visit_diagnosis`, `prescription`, `lab_test`.
Схема описана в `EMK_Aleksyuk_323.sql`, изменения версии 2 (анамнез, законный представитель, длинный столбец пароля) в `migration_v2.sql`.
